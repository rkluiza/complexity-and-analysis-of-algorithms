# Análise e Projeto de Algoritmos

Projeto desenvolvido para a disciplina de **Análise e Projeto de Algoritmos**, com o objetivo de implementar, analisar e comparar diferentes algoritmos de ordenação durante o semestre de 2026/2.

Durante o semestre, os algoritmos foram todos desenvolvidos em dupla e, em sua maior parte durante a aula.

## 📌 Objetivo

O repositório tem como objetivo abranger o semestre de 2026/2, compartilhando os códigos e análises desenvolvidos na disciplina de Análise e Projeto de Algoritmos.

Até o momento, foram implementados e analisados os seguintes algoritmos:

- Bubble Sort
- Selection Sort
- Quick Sort
- Shell Sort
- Merge Sort

Os algoritmos foram executados com diferentes quantidades de elementos definidos posteriormente, permitindo observar como o aumento do tamanho da entrada influencia o desempenho de cada implementação.
